Install & get started +

This is a direct Android download. There is no iPhone version.

  1. Download the APK, the Android installation file. Open it and, if asked, allow your browser or file manager to install this app.
  2. Open Even Care. Its setup takes you to Android settings for Do Not Disturb access and Display over other apps, which lets it draw the dim layer.
  3. Allow notifications when asked, so you can see the running service. Return to the app, check the permissions, choose your night hours and use the main switch.
  4. Try an on/off cycle. Check screen touches and sound, and make sure switching off removes the dim layer. Keep an eye on the first real hour change.

You can turn off your browser's installation permission afterwards. If Android blocks installation, read its explanation and keep general security protections enabled.

No ADB, Shizuku or computer setup is needed for this dimming version. Battery management can affect background behavior; the beta has not been verified on every phone.

What it does, and what stays yours +

Even Care dims with a dark, transparent layer. It does not turn the display grayscale or block your apps. Less screen time is an intention, not a measured or guaranteed result.

Ending a quiet period restores the Do Not Disturb setting from before it. A manual change to a different Do Not Disturb mode during the pause is preserved. Other scheduling apps can still interact with these settings.

No account, analytics or internet permission is built into the app. Android may back up its settings. The app follows your phone's language: English, Dutch, French or German.

This website has no analytics or tracking cookies. Its host processes network requests, and its fonts are loaded from Google Fonts.

Beta, updates & release details +

Version 1.1-beta.1. Tested in an Android 15 emulator; not yet tested on a physical phone. Real hour changes, overnight use, restart and manufacturer battery restrictions still need device testing.

For future updates, return here and install the new APK over this beta. An older development or GitHub debug build may use a different signing key. If Android refuses to update it, note your settings before removing the old build; reinstalling can reset them.
