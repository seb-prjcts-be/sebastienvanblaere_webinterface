# Template — remove or overwrite

This is an example entry for the **writings** collection. Just drop your text in `nl.md`, `en.md`, `fr.md`. Real Markdown is fine — Parsedown renders it to HTML.

## Markdown works

- Lists
- *italic*, **bold**, `code`
- [Links](https://prjcts.be)
- Footnotes via inline HTML if needed

> Quotes render with a red left border.

## Aside

Optional: drop an `aside_nl.md` (en/fr) for footnotes, bibliography or context. It appears below the main article with a thin separator.

## Media

Drop images, videos, audio or PDFs in this folder — they appear automatically in a grid at the bottom.

## Meta

In `meta.json`:
- `type` — `essay` / `story` / `research` / `letter`
- `date` — ISO format (`2026-05-03`); sort is desc on this date
- `title_nl/en/fr` + `subtitle_nl/en/fr` — per language
