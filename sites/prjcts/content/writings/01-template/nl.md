# Template — verwijder of overschrijf

Dit is een voorbeeld-entry voor de **writings**-collectie. Drop je tekst gewoon in `nl.md`, `en.md`, `fr.md`. Het mag echte Markdown zijn — Parsedown rendert het naar HTML.

## Markdown werkt

- Lijsten
- *Cursief*, **vet**, `code`
- [Links](https://prjcts.be)
- Voetnoten via inline HTML als nodig

> Citaten worden netjes gerenderd met een rode rand links.

## Aside

Optioneel: drop een `aside_nl.md` (en/fr) voor voetnoten, bibliografie of context. Dat verschijnt onderaan het hoofdartikel met een dunne lijn ertussen.

## Media

Drop afbeeldingen, video's, audio of PDF's gewoon in deze folder — ze verschijnen automatisch in een grid onderaan.

## Meta

In `meta.json`:
- `type` — `essay` / `story` / `research` / `letter`
- `date` — ISO-formaat (`2026-05-03`); sortering is desc op deze datum
- `title_nl/en/fr` + `subtitle_nl/en/fr` — per taal
